دليل سلمية - نسخة Supabase

1) افتح Supabase > SQL Editor والصق محتوى database.sql ثم Run.
2) ارفع جميع الملفات الموجودة في هذا المجلد إلى GitHub Pages.
3) لوحة الإدارة: admin.html ورمز الدخول 1234.
4) بيانات المحلات والأقسام وإعدادات الواجهة تحفظ الآن في Supabase.
5) الصور ترفع من الجهاز وتُخزن مضغوطة داخل بيانات المشروع.
ملاحظة أمنية: رمز 1234 حماية واجهة فقط. قبل الاستخدام التجاري يفضّل ربط لوحة الإدارة بـ Supabase Auth وصلاحيات RLS حقيقية.
